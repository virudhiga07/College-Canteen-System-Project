
# VCET College Canteen – Project Scope

## Objective

To develop a College Canteen Ordering and Sales Analysis System using Java and PostgreSQL. The system manages food items, processes customer orders, calculates bills, maintains stock quantities, stores transaction records and analyzes sales data using Python.

## Included Modules

1. **Food Item Management:** Add, view, update and manage food item details such as food name, category, price and stock quantity.

2. **Order Processing:** Accept orders containing one or more food items and their respective quantities.

3. **Billing:** Automatically calculate individual item subtotals and the total bill amount.

4. **Inventory Management:** Check available stock before accepting an order and reduce stock quantities after successful order completion.

5. **Transaction Management:** Store order details and individual order items in the PostgreSQL database.

6. **Sales Reporting:** Generate sales reports showing total number of orders, total revenue, average order value and item-wise sales.

7. **Python Data Analytics:** Retrieve sales data from PostgreSQL, preprocess and analyze the dataset using Python and Pandas.

8. **Data Visualization:** Generate visualizations representing item-wise sales, daily revenue and popular food items.

## Technologies Used

- Java 17
- Maven
- JDBC
- PostgreSQL
- Python
- Pandas
- Matplotlib
- Psycopg2
- python-dotenv

## Not Included

The following features are outside the scope of this project:

- Customer account registration and login
- Online payment gateway
- Food delivery tracking
- Mobile application
- Web-based frontend
- Multiple staff roles and role-based access

## Expected Outcome

The project provides a simple console-based canteen management application that reduces manual work in order processing, billing and inventory management. It also helps identify popular food items and understand sales trends through Python-based data analysis and visualization.
